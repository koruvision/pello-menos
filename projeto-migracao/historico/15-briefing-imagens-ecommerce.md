## Objetivo

Refazer **todas** as imagens de produto/serviço do e-commerce (feminino e masculino), com qualidade de campanha, no padrão visual definido abaixo. **Não** reutilizar as imagens atuais do site como entrega final — elas servem só de contexto quando houver referência da loja. A única referência visual **obrigatória** de estilo feminino é **Axila – Cera** (`axila-cera`).

## Especificações técnicas (todas as fotos de serviço)

| Item | Especificação |
|------|----------------|
| Formato de entrega | **WebP** (qualidade alta, sem artefato) |
| Proporção | **4:5** (retrato — card do site) |
| Tamanho recomendado | **1080 × 1350 px** (export final); mínimo aceitável **864 × 1152 px** |
| Nome do arquivo | Igual ao ID do produto + `.webp` (ex.: `axila-cera.webp`, `peito-cera-masc.webp`) |
| Pasta lógica | Feminino: `products/`; Masculino: `products/male/` |
| Fundo / luz | Limpo, clínico-suave, pele bem iluminada; área do serviço clara e legível |
| Texto na imagem | Evitar texto; se precisar, mínimo e legível |

Planos / clube: podem ser artes 4:5 no mesmo tamanho, sem foto de corpo se a campanha for gráfica.

## Padrão visual

### Feminino — referência obrigatória

- **Modelo de estilo:** produto **Axila – Cera** (`axila-cera`).
- Tom: foto de campanha, área marcada/visível, estética spa/clínica, enquadramento 4:5.
- Todas as demais fotos femininas devem parecer da **mesma sessão / mesmo tratamento visual** (cor, luz, crop, pele, ausência de poluição visual).
- Imagem de referência na loja (axila-cera): https://loja.pellomenos.com.br/wp-content/uploads/2021/12/204129pia_9depilacaocera_1000x1000px-e1692816124501.webp

### Masculino — referência de guarda-roupa

- **Cueca:** boxer / box **branca** sempre que a região inferior ou tronco aparecer.
- **Com camisa:** áreas de rosto / barba / bigode / pescoço / orelha / nariz / queixo / sobrancelha (camisa ou gola discreta).
- **Sem camisa:** peito, abdômen, tórax, costas, axila/braço quando a área exigir, virilha, nádegas, pernas, coxa, etc.
- Não há equivalente masculino na loja oficial — coluna de referência da loja fica **vazia**; seguir só este briefing + coerência com o set masculino.
